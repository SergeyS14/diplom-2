# Онлайн-квиз (диплом)

TV-экран + PWA игроков + NestJS. Подробный план: [`docs/PLAN.md`](docs/PLAN.md).

## Что умеет

- Эфир на ТВ: пароль показа, лобби с QR, раунды, вопросы, рейтинг, реклама, подиум. Код комнаты виден всё время игры
- Шоу крутится само (старт, вопросы, паузы, новый круг) — ведущий из аккаунта не нужен
- PWA: вход по QR/коду, регистрация, профиль, аватар, глобальный рейтинг
- Студия квизов — только у админа

Гость может зайти по коду без аккаунта. Рейтинг и медали — у подтверждённого игрока.

## Запуск

Нужны Node 20+ и **Docker Desktop**.

```bash
cp .env.example apps/api/.env
npm ci
npm run setup
npm run dev
```

`setup` поднимает PostgreSQL и Mailhog, накатывает миграции и seed.

| URL | Зачем |
|---|---|
| http://localhost:5173 | ТВ — пароль показа `show123` |
| http://localhost:5174 | Игрок (QR / код с экрана) |
| http://localhost:3000/api/health | API |
| http://localhost:8025 | Mailhog — письма подтверждения |

Демо:

- ТВ: пароль показа `show123`
- `player@quiz.local` / `diplom123` — игрок с аватаркой и медалями
- `admin@quiz.local` / `diplom123` — студия контента

Новая регистрация: письмо в Mailhog, ссылка `/verify?token=…`.

## Стек

Vue 3, Pinia, NestJS, Socket.IO, Prisma, PostgreSQL, Mailhog.

## Управление эфиром

Через 10 секунд после открытия показа начинается игра, даже если зал ещё пуст. Игрок может подключиться в середине вопроса. Для игры с телефона откройте ТВ по LAN-адресу компьютера и добавьте адреса фронтендов в CORS_ORIGIN. Если приложения работают на разных хостах, укажите VITE_API_URL в окружении клиентов и VITE_PLAYER_URL в окружении ТВ.

Администратор входит в приложение игрока и открывает «Студию». Панель показывает активные комнаты и очередь. Позиции задаются числами от 1 до 9999. При совпадении первым идёт раньше созданный квиз. Снятие с публикации убирает игру из следующих показов. Если очередь опустела, экран остаётся на подиуме и сервер повторно проверяет очередь каждые 18 секунд.

Рекламную карточку можно создать или изменить в редакторе квиза и назначить раунду. Поддерживаются текст, изображение и прямая ссылка на MP4, WebM или OGV. Длительность задаётся в секундах. Контент текущей партии фиксируется при загрузке квиза. После подиума код комнаты сохраняется, счёт начинается заново.

Для первого запуска используйте новый том PostgreSQL. Seed заполняет базу только при отсутствии пользователей. В истории проекта осталась разрушающая миграция первого прототипа.

Сценарии для диплома приведены в [методике испытаний](docs/TESTING.md).

В студии у каждого вопроса есть поле «Ссылка на картинку». Вставьте прямой HTTP(S)-адрес изображения и сохраните вопрос. Картинка показывается на ТВ и в приложении игрока. Для удаления очистите поле и сохраните вопрос снова.
