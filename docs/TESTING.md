# Испытания дипломного проекта

Запускайте проверки из корня проекта после npm ci. Интеграционный набор запускает NestJS на свободном порту и применяет все миграции в отдельной схеме PostgreSQL со случайным именем. После испытания схема удаляется. Пользователю тестовой базы нужны права создания схем.

```sh
npm test
TEST_DATABASE_URL=postgresql://quiz:quiz@127.0.0.1:5433/quiz npm run test:integration
```

Для проверки интерфейса задайте также переменную TEST_BROWSER с полным путём к исполняемому файлу Chrome или Chromium. Тест сам запустит браузер, Vite и API.

| Условие | Проверяемый результат |
|---|---|
| Неверный ответ, разная скорость, длинная серия | Ноль за ошибку, границы бонусов за скорость и серию |
| Частично заполненный и случайный аватар | Восстановление значений по умолчанию и сохранение черт |
| Игрок открывает REST-метод студии | HTTP 403 |
| ТВ запускает показ без участников | Через 10 секунд появляется первый раунд по порядку эфира |
| Участник подключается в середине вопроса | Получает текущие варианты, может ответить один раз |
| Второй ТВ подключается во время раскрытия ответа | Экран получает исходный вопрос и результаты с числом голосов |
| ТВ запускает отдельный показ | Комнаты имеют разные коды и независимые списки игроков и стадии |
| Вопрос содержит ссылку на картинку | Студия сохраняет ссылку, Chromium загружает изображение у игрока и на ТВ |
| Редактор меняет рекламу будущего раунда | Следующая игра содержит изменённую карточку, раунд без привязки пропускает рекламу |
| Повторяется первый квиз | Код и игрок сохраняются, оба ответа записываются в разные циклы |
| Администратор открывает панель эфира | Видит код, название квиза и число подключённых игроков |
| Профиль на экране 390 × 844 | Выбранная причёска сохраняется после перезагрузки |
| Администратор меняет позицию через браузер | Сохранённая позиция читается через API |

Автостарт проверяется по настоящему таймеру и событию Socket.IO. Переходы между последующими сценами тест ускоряет вызовами игрового сервиса. Профиль и редактирование очереди проверяются в одном браузерном сценарии.
